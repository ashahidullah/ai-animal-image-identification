# AI-Powered Animal Image Identification Using IBM watsonx.ai

## Project Overview
This project demonstrates the application of artificial intelligence and computer vision to identify and describe animals from images using IBM watsonx.ai and Python.

## Technologies Used
- Python
- IBM watsonx.ai
- Llama 3.2 Vision Instruct
- Google Colab
- Pillow
- IBM watsonx AI SDK

## Project Objectives
- Identify animals from uploaded images.
- Generate physical descriptions of detected animals.
- Describe animal activities.
- Provide qualitative confidence levels.
- Process multiple images automatically.

## Methodology
1. Configure IBM watsonx.ai credentials.
2. Initialize the vision-language model.
3. Load and encode images.
4. Submit images to the model.
5. Generate animal identification and descriptions.
6. Display the results.

## Example Results
The model was tested with images of an owl, a German Shepherd dog, and a dolphin.
